**Slugs to support:**
- `mike` - Mike (Sales Development)
- `sarah` - Sarah (Customer Success)
- `alex` - Alex (Content Marketing)
- `casey` - Casey (Operations)
- `lumen` - Lumen (Engineering)
- `flux` - Flux (Creative)

**Page sections:**
1. **Hero** - Agent name, tagline, avatar
2. **Overview** - What this agent does, key capabilities
3. **Skills** - List of skills/tools with icons
4. **Use Cases** - Real scenarios this agent handles
5. **Sample Work** - Examples of output (if applicable)
6. **Integration** - How it works with your systems
7. **CTA** - "Hire [Name]" button → /portal

### 3. Generate Static Params

Implement `generateStaticParams()` for all agent slugs:
```typescript

```
