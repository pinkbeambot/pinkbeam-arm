## Task
Build the decisions API for logging and retrieving agent decisions — the audit trail of agent reasoning.

## Endpoints to Implement

### GET /api/decisions
List decisions with filtering support:
- `agent_id` - Filter by agent
- `category` - Filter by decision category
- `status` - proposed, approved, rejected, overridden, executed
- `date_from` / `date_to` - Date range
- `confidence_min` - Minimum confidence threshold
- `search` - Full-text search on title/description
- `page`, `limit` - Pagination

### POST /api/decisions
Log new decision (called by agent runtime):
- Required: agent_id, category, title, description, reasoning, confidence
- Optional: proposed_action, metadata
- Returns: 201 with created decision

### GET /api/decisions/[id]
Get single decision details with full context

### GET /api/decisions/stats
Aggregated statistics:
- Count by category
- Count by status
- Average confidence per agent
- Decisions over time (daily counts)

## Decision Schema

Key fields from database:
- id, tenant_id, agent_id
- category (string)
- title, description, reasoning
- confidence (0-1 float)
- proposed_action (JSON)
- status: proposed | approved | rejected | overridden | executed
- approver_id (if overridden/approved)
- created_at, updated_at
