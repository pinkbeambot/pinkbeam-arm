## Requirements

### 1. Advanced Filtering (GET /api/tasks)
Add query parameter support:
- `status` - Filter by status (single or comma-separated: `status=pending,in_progress`)
- `priority` - Filter by priority
- `agent_id` - Filter by assigned agent
- `parent_id` - Filter by parent task (null for root tasks)
- `due_before` - ISO date string
- `due_after` - ISO date string
- `search` - Search in title and description
- `sort` - Sort field (created_at, updated_at, due_date, priority)
- `order` - asc or desc

### 2. Batch Operations
- `POST /api/tasks/batch` - Create multiple tasks
- `PATCH /api/tasks/batch` - Update multiple tasks
- `DELETE /api/tasks/batch` - Delete multiple tasks (guarded)

### 3. Task Tree Operations
- `GET /api/tasks/tree?root_id=xxx` - Get full task tree
- Include depth, path, and children recursively

### 4. Validation
- Use Zod schemas from `src/lib/validation.ts`
- Validate batch operations (max 100 items)
- Validate date ranges

### 5. RLS & Security
- All operations must respect tenant context
- Use `set_tenant_context` RPC
- Verify agent ownership before assignment
