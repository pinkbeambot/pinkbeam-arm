## Task
Implement full CRUD endpoints for `/api/agents` with Zod validation, RLS checks, and TypeScript types.

## Requirements

### Endpoints
1. **GET /api/agents** - List agents with filtering
   - Query params: `status`, `role`, `search`, `page`, `limit`
   - Include agent stats and parent info
   
2. **POST /api/agents** - Create a new agent
   - Body: name, role, description, parent_id, capabilities, llm_config, limits
   - Auto-assign tenant_id, root_id, depth based on parent
   
3. **GET /api/agents/:id** - Get single agent
   - Include parent, children, current task, recent activities
   
4. **PATCH /api/agents/:id** - Update agent
   - Body: name, description, status, capabilities, llm_config, limits
   
5. **DELETE /api/agents/:id** - Delete agent
   - Only if status is 'terminated' or 'initializing'

### Technical Requirements
- Zod validation using existing schemas in `src/lib/validation.ts`
- RLS checks via `set_tenant_context` RPC
- TypeScript strict mode
- Follow patterns from `/api/tasks` endpoints
- Activity logging handled by database triggers
