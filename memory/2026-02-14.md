## Issue #144 - Portal "Tenant not found" Errors (1:02 PM - 1:30 PM)

**Problem:** All portal pages showing "Tenant not found" errors after login  
**Pages Affected:** /portal, /portal/agents, /portal/activity, /portal/decisions, /portal/metrics, /portal/performance

- Portal pages using hardcoded `DEMO_TENANT_ID` instead of real tenant from user session
- `useDashboardStats` hook querying Supabase directly without RLS tenant context

- Created `/api/user/tenant` endpoint
- Created `useTenant()` hook for React components
- Created `/api/dashboard/stats` endpoint with proper RLS
- Updated `/portal/agents/page.tsx` and `useDashboardStats.ts`
