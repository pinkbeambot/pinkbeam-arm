## Issue #145 - API 403/401 Errors (1:30 PM - 1:41 PM)

**Problem:** Portal pages load but API calls return 403/401 errors
**Errors:**
- GET /api/agents?limit=100 403
- GET /api/tasks?page=1&limit=100 403
- GET /api/activities?limit=50 401

**Root Cause:** RLS tenant context not persisting across queries with connection pooling in API routes

**CTO Investigation (6m55s):**
- Identified API routes not setting tenant context for RLS
- Compared working Edge Functions vs failing API routes
- Created solution using service role client in API routes (server-side only)

**Files Fixed:**
- New: `src/lib/supabase/service-role.ts`
- Fixed: `/api/agents`, `/api/tasks`, `/api/activities`, `/api/decisions`, `/api/escalations`, `/api/messages`, `/api/costs`, `/api/agent-templates`

**Result:** All API endpoints now return proper data; 401 for invalid auth instead of 403 RLS errors
