### 2. Mobile Strategy - Desktop-First, Mobile-Adequate
**Decision:** Build desktop-first (1440px+) with responsive down to tablet. Mobile gets a "companion" experience only.

**Rationale:**
- ARM is a command center with information density that doesn't shrink gracefully
- Target users (solopreneurs managing AI agents) do deep work at desks
- Mobile use cases are limited to: escalation approval, quick status checks, chat

**Build order:**
1. Nail desktop (80% of value)
2. Add tablet responsiveness (15%)
3. Ship mobile companion later (5%)
